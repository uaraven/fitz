1. LibRaw (RAW camera file support)
------------------------------------

libfitz reads RAW files from digital cameras through the `rsraw` and
`rsraw-sys` crates (MIT; https://github.com/hexilee/rsraw). `rsraw-sys`
vendors the LibRaw C++ library (https://www.libraw.org/) and compiles it
directly into the fitz/libfitz/FitSmith binaries via its build.rs (a static
`cc` build, not a link against a system libraw.so/.dylib/.dll).

LibRaw is dual-licensed by LibRaw LLC, at the licensee's option, under:

  1. GNU Lesser General Public License, version 2.1 (LGPL-2.1), or
  2. Common Development and Distribution License, version 1.0 (CDDL-1.0)

fitz uses LibRaw under the CDDL-1.0. Full text: LICENSES/CDDL-1.0.txt.

Why CDDL-1.0 and not LGPL-2.1: LibRaw is compiled straight into a static
Rust binary rather than linked as a shared library. LGPL-2.1's compliance
path (section 6) is written around shared-library linking, or otherwise
requires distributing the application in a form that lets a user relink it
against a modified copy of the library -- extra mechanics that don't map
cleanly onto a statically-linked Rust build. CDDL-1.0's copyleft is scoped
to the covered *files*, not to how they're linked or combined: since fitz
redistributes LibRaw's original, unmodified source exactly as vendored by
rsraw-sys, compliance is simply attribution, the license text, and the
source itself (all satisfied here) with no linking-mode-dependent
obligations. This choice governs only the LibRaw source files; it does not
change the MIT license of fitz's own code.

LibRaw itself bundles a few other openly-licensed components (per its own
COPYRIGHT file, vendored alongside it by rsraw-sys):

  - dcraw.c (non-restricted portions) -- Copyright 1997-2018 Dave Coffin
  - DCB demosaicing and FBDD denoise -- Copyright (c) 2010 Jacek Gozdz,
    BSD-style 3-clause license
  - the X3F library (Foveon file support) -- Copyright (c) 2010 Roland
    Karlsson, BSD-style license
  - portions of the Adobe DNG SDK 1.4 -- Copyright (c) 2005 Adobe Systems
    Incorporated, MIT license
